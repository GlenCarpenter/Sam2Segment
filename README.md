# Sam2Points Extension

Adds a SAM2 point-based and bounding box mask tool to the image editor.

## Notes for point tool
- Left click adds positive points.
- Right click adds negative points (context menu is disabled).
- Each click regenerates the mask preview and applies it to the mask layer.

## Notes for bounding box tool
- Only supports a single bounding box

## Build
Run SwarmUI using the dev launch script or run update to rebuild.
